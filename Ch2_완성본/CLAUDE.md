# CLAUDE.md

이 프로젝트는 AI 반도체(HBM, GPU, NPU 등) 시장조사 보고서를 작성합니다.

## 범위 제한
- 반드시 현재 폴더(Ch4_완성본) 내부에서만 작업하세요.
- 상위 폴더(`..`) 또는 다른 상위 경로 접근을 절대 금지합니다.
- 파일 생성/수정은 이 폴더 및 하위 폴더로 한정합니다.

## 작업 가이드
- 보고서는 시장 규모, 주요 기업, 기술 동향, 전망 순으로 구성합니다.
- 최신 통계·수치는 출처를 명시합니다.
- 산출물은 markdown 또는 요청 형식(pptx 등)으로 작성합니다.
- 불확실한 수치는 추정임을 명시하고 과장하지 않습니다.

## 스타일
- 보고서는 한국어로 작성합니다.
- 간결하고 객관적인 문체를 사용합니다.

## 서브에이전트 위임 규칙
1. market-analyst, supplier-analyst, demand-analyst를 동시에 병렬 호출해 조사(data/*.md 생성).
2. 셋이 모두 끝난 뒤 report-writer를 호출해 report/*.md 작성.
3. 이어서 report-reviewer를 호출해 검토·피드백 1개 전달.
4. 마지막으로 report-writer를 다시 호출해 피드백 반영 수정(1회) 후 종료.
