## 1. 제목 (Headings)

`#` 기호의 개수로 제목 레벨(1~6)을 지정합니다.

```markdown
# 제목 1
## 제목 2
### 제목 3
#### 제목 4
```

> 💡 `#` 뒤에는 **반드시 공백**을 한 칸 넣어야 합니다.

---

## 2. 텍스트 강조

| 표현 | 문법 | 결과 |
|------|------|------|
| 굵게 | `**텍스트**` | **텍스트** |
| 기울임 | `*텍스트*` | *텍스트* |
| 굵게 + 기울임 | `***텍스트***` | ***텍스트*** |
| 취소선 | `~~텍스트~~` | ~~텍스트~~ |
| 인라인 코드 | `` `텍스트` `` | `텍스트` |

## 3. 목록 (Lists)

### 🔹 순서 없는 목록

`-`, `*`, `+` 중 하나를 사용합니다.

```markdown
- 사과
- 바나나
  - 들여쓰기로 하위 항목
```

- 사과
- 바나나
  - 들여쓰기로 하위 항목

### 🔸 순서 있는 목록

```markdown
1. 첫 번째
2. 두 번째
3. 세 번째
```

1. 첫 번째
2. 두 번째
3. 세 번째

## 4. 링크와 이미지

```markdown

```

- 🔗 링크: [Markdown 공식 가이드](https://www.markdownguide.org)
- 🖼️ 이미지는 링크 앞에 `!`만 붙이면 됩니다.

## 5. 코드

### ▶ 인라인 코드

문장 중간에 `print("Hello")`처럼 백틱(`` ` ``)으로 감쌉니다.

### ▶ 코드 블록

백틱 3개(```` ``` ````)와 **언어 이름**을 적으면 문법 강조가 적용됩니다.

````markdown
```python
def hello():
    print("Hello, Markdown!")
```
````

```python
def hello():
    print("Hello, Markdown!")
```

## 6. 인용문

`>` 기호를 사용하며, 중첩도 가능합니다.

```markdown
> 인용문입니다.
>> 중첩된 인용문입니다.
```

> 인용문입니다.
>> 중첩된 인용문입니다.

## 7. 표 (Tables)

`|`로 열을, `-`로 헤더 구분선을 만듭니다. `:`로 정렬을 지정합니다.

```markdown
| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:----------|:-----------:|------------:|
| A         | B           | C           |
| 1         | 2           | 3           |
```

| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:----------|:-----------:|------------:|
| A         | B           | C           |
| 1         | 2           | 3           |

## 8. 체크리스트

```markdown
- [ ] 해야 할 작업
```

- [x] 완료된 작업
- [ ] 해야 할 작업

---

## 9. 구분선과 줄바꿈

- ➖ **구분선**: `---`, `***`, `___` 중 하나
- ↩️ **줄바꿈**: 줄 끝에 공백 2칸 또는 `<br>` 사용
- ¶ **문단 구분**: 빈 줄 한 줄 넣기

## 10. 기타 팁

| 기능 | 문법 | 비고 |
|------|------|------|
| 이스케이프 | `\*별표\*` | 기호를 문자 그대로 출력 |
| 각주 | `텍스트[^1]` / `[^1]: 설명` | GitHub 등 지원 |
| 접기 | `<details><summary>제목</summary>내용</details>` | HTML 태그 활용 |
| 이모지 | `:smile:` → 😄 | 플랫폼에 따라 다름 |
