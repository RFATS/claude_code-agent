# 대시보드 화면 만들기

주제: $ARGUMENTS (비어 있으면 임의의 주제를 골라 진행한다)

## 절차

1. `samples/dashboard-sample.html`을 읽고 디자인 시스템을 파악한다.
2. 주제에 맞는 지표·항목·수치(임의의 예시 데이터)를 구성한다.
3. 프로젝트 루트에 `<영문-주제>.html`로 저장한다. 기존 파일은 덮어쓰지 않고, 같은 이름이 있으면 사용자에게 알린다.
4. 마지막에 파일 경로와 구성(섹션 목록)을 짧게 보고한다. 수치가 예시 데이터임을 밝힌다.

## 디자인 규칙 (샘플과 동일하게 유지)

- 배경 `#EEF0F5`, 텍스트 `#0A1547`, 헤더·다크 카드 `#0A1547`
- 블루 계열 팔레트: `#1428A0` `#4B5CC0` `#7C9BFF` `#C2C8E8` `#DCE0E9`, 경고 `#B0472F`·`#C98A2E`
- 폰트: 제목·숫자 "Gothic A1", 본문 "Noto Sans KR" (Google Fonts 링크 포함)
- 카드: 흰 배경, 1px `#E1E4EC` 테두리, 둥글기 12px
- 차트는 외부 라이브러리 없이 CSS/인라인 SVG로 그린다.
- 단일 HTML 파일, `lang="ko"`, 한국어 콘텐츠

## 화면 구성 (샘플 순서)

1. 헤더: 영문 eyebrow, 제목, 기준일, 기간 탭, 핵심 지표 4개 줄
2. KPI 카드 4~5개 (스파크라인·미니 막대·도넛 혼합)
3. 메인 차트(선/면) + 구성비 도넛
4. 3열: 누적 막대 추이, 순위 막대, 분석 요약(다크 카드, "다음 조치" 포함)
5. 상세 테이블 + "점검 필요" 목록

## 주의

- 스타일은 `<style>` 블록의 클래스로 정리하고, 좁은 화면에서 열 수가 줄어드는 반응형 미디어쿼리를 넣는다.
- 요약 문장의 수치는 차트·표의 수치와 서로 맞아야 한다.
