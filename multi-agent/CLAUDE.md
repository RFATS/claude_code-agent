# AI 반도체 시장조사 보고서

## 프로젝트 목표
AI 반도체 시장 규모·공급사·수요처를 웹에서 조사하고, 짧은 HTML 보고서(`report/report.html`)를 만든다.

## 공통 작업 규칙
- 이 프로젝트 폴더 안에서만 작업한다. 상위 폴더는 절대 접근하지 않는다.
- 조사 결과는 `data/*.md`, 보고서는 `report/`에 저장한다.
- 모든 수치에는 출처를 표시하고, 못 찾은 내용은 "못 찾음"으로 쓴다.
- 요청하지 않은 파일이나 폴더는 만들지 않는다.

## Sub Agent 위임 규칙
직접 조사·작성하지 말고 아래 순서로 위임한다.
1. `market-analyst`, `supplier-analyst`, `demand-analyst`를 동시에 실행해 조사한다.
2. 세 조사가 모두 끝나면 `report-writer`가 보고서를 작성한다.
3. 작성이 끝나면 `report-reviewer`가 검토한다.
4. 피드백이 있으면 `report-writer`가 1회 수정하고 종료한다. 추가 검토는 하지 않는다.
